# Carnet Muscu UTMB

Carnet de séances de renforcement pour la prépa UTMB 2027 : programme en 3 phases, saisie charge/reps par série, chrono de récup, suivi douleur sacrum (pendant et au réveil).

- Les données restent dans le téléphone (stockage du navigateur). Export/import JSON dans l'onglet Historique.
- Sur iPhone : ouvrir dans Safari → Partager → « Sur l'écran d'accueil ».
- Fonctionne hors ligne après la première ouverture.
